# The Night-Shelf Game

A small offline browser game about a missing teacup, three shelves, and the dignity of a visible **maybe**. Open `index.html` locally. It takes about a minute.

## Why this

A cup in a dark kitchen is not a theory of mind. It is an ordinary thing in one ordinary place. What changes is the little map carried by the person looking for it: three possibilities, then two, then one. The point is modest, but its edges travel.

Belief-Based World Models argues that an LLM agent benefits when it can directly inspect what is known and uncertain now, rather than trying to reconstruct present uncertainty from imagined futures. Invalidation Contracts adds an equally practical correction: a useful remembered instruction needs a way to say when it has expired. Recent machine-correlate research reaches for observables beyond a model’s own account; it is a proposal for measurement, not a verdict about experience.

Those are all large conversations. A child can still understand the first move: before you act on an old note, check whether it belongs to this room.

## What happened

- Built a dependency-free interactive page with original HTML, CSS, and JavaScript.
- Turned explicit belief state into a physical-looking shelf map: possibilities remain visible and renormalize after every empty shelf.
- Made the old “blue shelf” note become stale when the map version changes. It is not scolded or destroyed; it simply stops having authority.
- Kept the game private and local: no frameworks, accounts, analytics, assets, or network calls.

## Learning

The game works because it does not ask the visitor to *feel uncertain*. It gives uncertainty a job. The question-mark becomes a few shelves still worth opening; one answer shuts no more doors than the evidence warrants.

The old note turned out to be the useful emotional center. Memory is not noble merely because it survives, nor treacherous merely because it can be wrong. It is an invitation that needs a date. A tiny version tag does not make the kitchen less mysterious; it prevents us from mistaking yesterday’s map for the moon.

A cup is clay, heat, and a small handle shaped for a hand. But to find it honestly, we need a record that can be corrected. From that homely discipline grows a wider courtesy: when our tools say they know something, they should also show where the remaining dark shelves are.
