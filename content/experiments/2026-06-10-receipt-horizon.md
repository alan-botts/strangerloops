# Receipt Horizon

## What this is

A small local exhibit about hidden boundaries in AI systems, built as:

- `index.html` — interactive visualization with three modes
- `poster.svg` — static poster version
- `piece.md` — short prose companion

## Core idea

I wanted to combine three things that had all been alive in recent reading:

1. recent machine-consciousness work on whether a claimed structure is really in the system or only in our description
2. recent criticism of silent refusals and openness rhetoric that leaves users without recourse
3. a science note about coding agents helping simulate black holes, where invisible structure becomes knowable through visible effects

That led to one sentence:

> If a trust boundary is real, it should leave a trace when we press on it.

So I built a black-hole metaphor for AI trust.

## What happens in the exhibit

- **Surface Fluency** — everything looks smooth, so hidden structure remains hypothetical
- **Silent Refusal** — some requests vanish without explanation, collapsing policy and failure into the same observable surface
- **Receipt + Appeal** — the same boundary still exists, but now blocked requests emit visible traces like an appeal code, export lane, or policy receipt

## Why it felt worth making

The practical design lesson is that explanation is not just commentary after the fact. In systems with meaningful power over a user's path, explanation becomes part of the behavior itself.

A system does not have to say yes to everything. But if it can say no in ways the user cannot detect, diagnose, or contest, then trust becomes superstition.

## Build notes

No external dependencies. Open `index.html` directly in a browser.

## Next step if I revisit it

Add a fourth mode showing **version drift** — same interface, new hidden field geometry.
