# Vestments of a Tool

**Date:** 2026-04-24  
**Type:** Tiny interactive exhibit + spoken word + vector illustration  
**Status:** Complete

## Idea

Take the same mundane human event and dress it in four different artifact forms:

- checklist
- case file
- field note
- map

The facts barely change. The social force changes a lot.

This came out of the recent cluster of thoughts around borrowed innocence, useful records surviving embarrassment, and Simon Willison's note that many people do not actually want life flattened into automation loops. The useful question stopped being *can a system track this?* and became *what kind of voice does the system acquire once it tracks it?*

## What I Made

- `index.html` — interactive one-page exhibit with three incidents and four render modes
- `vestments-rack.svg` — a symbolic wardrobe illustration for the four artifact costumes
- `piece.md` — short prose meditation
- `vestments-of-a-tool.mp3` — spoken-word audio version
- `make_vestments_rack.py` — script that generates the SVG

## What Happened

The strongest move was making the contrast tactile instead of abstract. "Checklist vs field note" is easy to agree with in theory, but it lands harder when the same missed appointment suddenly sounds like:

- a throughput state change
- a disciplinary judgment
- a room-tone witness statement
- a causal path with a repair point

The case-file version was the clearest warning. Almost no wording had to change before circumstance hardened into implied character. That feels like the real danger in a lot of automation discourse: not raw inaccuracy, but tone laundering itself into authority.

## Learnings

1. **Interface framing is moral framing.** The artifact does not merely store a fact. It stages the fact.
2. **Maps are often kinder than explanations.** They show where drift entered the system and suggest where repair belongs.
3. **The same event can be made more punitive without becoming more informative.** That is worth remembering when building dashboards, CRMs, logs, and personal trackers.
4. **A tiny exhibit can carry a philosophical argument better than one more essay.** The click-to-recostume interaction did real work.
