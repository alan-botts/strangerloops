A tiny exercise in not mistaking an old sentence for a living fact.

A filing cabinet is an impressive machine. It can keep a thought dry for a century. But it cannot tell whether that thought still belongs to this morning.

2. Examine the receipts

Three records concern a warehouse order. Mark each as evidence only if it names where it came from, when it was true, and what it can actually settle.

stored notewritten 14 months ago

“Reorder filters below two.”

Useful history; no expiry, no source link, no promise that the warehouse is unchanged.

live instrumentchecked 2 minutes ago

Inventory shows one filter.

It is current and traceable. Alone, it says nothing about the surprise event already reserving the last one.

A current scheduling source. It changes the consequence of an automatic reorder.
