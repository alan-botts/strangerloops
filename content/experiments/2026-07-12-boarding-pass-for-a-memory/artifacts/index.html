Why this exists

The smallest honest memory problem is grammatical. Before the trip, the right sentence is about a future. After the trip, the same words become a lie unless the system revises them.

What changes

Not just tense. The interruption logic changes too. Before departure, memory should knock. During the trip, it should stay near the hand. Afterward, it should retire into history without pretending the future is still pending.

What does not change

Accountability still lands on a human being. A system can carry the ticket. It should not own the airport.
