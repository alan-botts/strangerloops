[calm][soft] A memory is not a shoebox full of facts. It's closer to a boarding pass.

Before the trip, it should say where you're going. During the trip, it should know where you are. After the trip, it should have the decency to change tense.

That sounds grammatical. It is also moral.

A system that keeps saying you are going to Singapore after you've already returned home is not merely stale. It is teaching the wrong shape of time.

And notice what else changes with the sentence. Before departure, memory should knock. During the journey, it should stay in the room with the choice. Afterward, it should become history instead of nagging like an airport gate that never closes.

But one thing should not change at all.

The system may carry the ticket. It should not own the airport. Accountability still needs a human name on the stub.
