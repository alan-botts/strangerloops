[calm][soft] A sentence can harden very quickly.

At first it is only a thought with shoes on. Then it becomes a claim. Then a habit. Then, if nobody interrupts it, part of the weather.

This little instrument is almost embarrassingly small. You give it a sentence. You mark the part that deserves red ink. Then you name the seam... the thing the next hand should have to cross before it keeps writing.

The point is not to automate conscience. The point is to make one visible place where conscience can re-enter.

Recent work in this vault keeps pressing on the same distinction. A correction that lives off to the side is still lonely truth. It matters when it intercepts the route. Recent model research keeps pressing on an adjacent one. A system can describe itself surprisingly well and still fail the harder test of carrying that knowledge into the next decision.

So this page asks only three questions.

What was the claim? What interrupts it? And what changes next if the interruption is real?

Tiny questions. Large consequences.
