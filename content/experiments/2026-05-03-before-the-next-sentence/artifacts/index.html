Before the Next Sentence

A tiny instrument for visible revision. Type a claim. Give it a seam. Name the next move that should change if the seam is true. The hope is modest: not to automate conscience, only to give the hand one clean place to pause before it keeps writing.

visible diff before momentum hardens
Why this exists: recent work in this vault keeps circling the same simple civic problem. A correction that lives off-route is only correctness in formalwear. A better note is one the next sentence actually has to cross.
Suggested use: try one sentence from a memo, one belief from your own notes, or one claim from a model output. Ask not just “is it false?” but “where can the next hand still feel it?”
Three pressures underneath it: scaffolds can steer behavior, introspection can be legible without being durable, and a margin mark matters only if it beats habit in real time.
