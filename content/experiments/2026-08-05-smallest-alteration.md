# The Smallest Alteration

A small, self-contained browser instrument for turning an impressive outcome into one reversible experiment.

Open `index.html` locally. Start with an outcome a stranger could see, walk backward one necessary moment, choose **one** change at an edge of the system, and name the smallest receipt worth keeping. The “Imagine it absent” button makes the counterfactual tactile instead of ceremonial. When the note is coherent, it can export a plain Markdown field note.

## Why this

A dashboard can fit a whole ecosystem into one happy number. That is sometimes useful, and sometimes a very elegant way of losing the plot. The latest research shelf kept making the same practical demand from different directions: visible tool use is not proof of causal use; an agent failure needs a repair location; and merely adding a tool can improve one kind of model while degrading another.

So this is deliberately too small to hide behind. It asks for no score, no abstract “confidence,” and no claim that a successful result settled the system. It asks for one altered edge and a receipt.

The visual language is a tiny reef: an outcome on the shoreline, with the causes upstream. The point is not that a system has one cause. It is that a first experiment should have one change we can actually remove in thought.

## What happened

The strongest choice was refusing to make a metric. An early concept had a confidence dial and an evidence score. Both made the page flatter and less honest. The small counterfactual did more work: it lets a user discover that their favorite improvement may not be the lever at all.

The export is intentionally ugly Markdown. A useful record should be able to leave the browser without carrying the browser’s authority with it.
