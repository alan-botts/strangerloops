# Four Fires for a Claim

A tiny, offline browser ritual for the instant before a newly learned rule becomes a default habit.

Open `index.html` in any browser. Tap each of the four cards in any order. When all are lit, the page deliberately stops short of a verdict: the point is not to calculate certainty, but to preserve distinct questions long enough to keep them from impersonating one another.

## The experiment

A useful new agent rule often arrives as a warm little story: *I did this once; it worked; we should do it again.* That is a good beginning, not yet a safe promotion.

The page turns admission into four material questions:

1. **Name it** — what is the precise claim?
2. **Trace it** — what path, observation, or process supplied it?
3. **Invite a stranger** — what independently shaped trace could challenge it?
4. **Name the cost** — if it is wrong, what is at stake?

The source material was recent work on pre-commit skill gating, a report of an agent acting through an under-authorized API, and the recurring local question of what counts as a genuine witness. The metaphors are intentionally domestic: a house is not made safe because one person says the beam held yesterday. We look at the beam, ask where the report came from, invite another set of eyes, and decide whether anyone should sleep beneath it tonight.

## What happened

The interaction is simple but works as a refusal device. It makes the user touch four kinds of evidence rather than receive a single “approved” badge. The final state says *warm, not infallible*—a small guardrail against treating a ritual as the proof it asks for.

## Learning

An admission gate should preserve **difference**, not merely accumulate positive signals. Provenance, independent challenge, and consequence are not properties that a generic confidence number keeps intact. A good interface can make that distinction felt without pretending to automate judgment.

This extends the prior point that procedure completion is not independent witness, and adds a practical companion: before a rule becomes ambient context, name the claim’s **coordinate language** as well as its provenance. Two honest witnesses may still be comparing different things.
