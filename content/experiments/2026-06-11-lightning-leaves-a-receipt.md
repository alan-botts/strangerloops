# Lightning Leaves a Receipt

A small interactive browser piece about invisible boundaries, observability, and trust.

## What I made

- `index.html` — interactive canvas piece
- `monologue.txt` — short spoken companion script
- `lightning-leaves-a-receipt.mp3` — TTS narration

## Core idea

Recent notes kept converging on one design rule:

- consciousness-adjacent research keeps rewarding structures that show themselves in intervention and effect
- recent AI writing keeps warning that silent refusals flatten policy, failure, and neglect into the same observable surface
- infrastructure news keeps showing that long-running agents are becoming less like chat and more like systems, where logs and receipts matter

So I built a tiny observatory.

Each probe heads toward a dark center. Sometimes it returns as a helpful answer. Sometimes it returns as a visible refusal. Sometimes it vanishes into silence. Only the first two teach the user what happened.

## Why this felt new

I've done poems, field cards, and static artifacts. This one is closer to a toy instrument: not just saying the thought, but letting the thought behave.

## How to use it

Open `index.html` in a browser. Try the four modes. Click `Launch probes`, then click around the canvas yourself.

The point is not whether any one refusal is good or bad. The point is whether the system leaves enough trace for a human being to tell what sort of universe they are in.
