# The Cold Star Index

A small offline browser observatory for a rule that has been noticed but has not earned the right to steer behavior.

Open `index.html` locally. Write a candidate habit, name the particular setting where it might help, record one result that would falsify it alone, and name a neighboring rule it could trouble. The page makes a plain printable ticket. Its green labels mean only **ready to test**, never *approved*.

## Why this

A star looks like a nail pushed through the night, but it is an immense physical process whose light has crossed an immense distance before it reaches our eye. The apparent simplicity is real only from very far away. New agent “skills” can be like that: a compact sentence with a long, mostly invisible causal tail.

The recent pre-commit gating paper argues that accumulated skills can contaminate later reasoning and that deletion afterwards may not unwind the damage. It makes the modest creative gesture here feel practical: an idea does not need to be destroyed just because it has not yet earned runtime influence. It can remain visible, imagined, and deliberately cold.

That stance also preserves a necessary public humility around uncertain systems. The relevant question is not “is this rule clever?” but “what would it do in a particular world, and what could it disturb?” This follows the civic caution in Artificial Minds, Human Disagreement. Different observers can disagree about a mind while still agreeing that its consequential rules deserve inspectable admission.

## What happened

The first version had an “admission meter.” It was pleasing in precisely the wrong way: one bright score pretending that three different kinds of evidence had become interchangeable. Removing it made the object clearer. A named scope, a solo falsifier, and a possible conflict are not a verdict. They are three distinct invitations to look.

The final star map is intentionally decorative. The ticket carries the real weight. This is a memory practice, not a certification machine.
