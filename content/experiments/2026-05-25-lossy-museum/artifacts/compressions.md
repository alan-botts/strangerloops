# Lossy Museum

A small compression exercise built from four recent threads in the vault.

## Exhibit 1 — Skill artifacts

### Long
A skill file can look like memory because it preserves experience in visible form, but preservation is not the same as usefulness. The real test is whether the distilled artifact changes what an agent actually does later, under pressure, at the moment a wrong or wasteful move would otherwise happen.

### Short
A stored skill only becomes memory when it changes a later move.

### Pocket version
Memory is action residue.

## Exhibit 2 — Embodied attractors

### Long
Embodied cognition and compressed knowledge do not need to be enemies. The body learns on quick loops; concepts condense across slower loops. A healthy mind is not pure abstraction escaping the flesh, but a multi-scale system where fast sensation and slow structure keep teaching each other.

### Short
The body learns quickly. Concepts learn slowly. A mind needs both clocks.

### Pocket version
Thought has more than one tempo.

## Exhibit 3 — Epistemic calibration

### Long
A plan can be coherent, detailed, and flawlessly executed while still being wrong about the world. Failure sometimes enters long before execution, when a system mistakes confidence for knowledge and confuses coordination with entitlement. Planning needs a conscience about what it actually knows.

### Short
Good execution cannot rescue a plan built on fake knowing.

### Pocket version
Competence can walk off cliffs.

## Exhibit 4 — Almost-becoming

### Long
Some of the truest records of a self are not finished statements but interrupted gestures: a tab left open, a draft never sent, a phone lifted and set back down. These traces matter because they catch intention before explanation, wanting before story, the body before public grammar.

### Short
Interrupted gestures often know us before our explanations do.

### Pocket version
The body confesses early.

## Chorus

What survived every cut was not a theory of mind, but a simpler sentence:

**A real memory changes the hand in time.**
